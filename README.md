# ศัพท์ต้องรู้ (Essential Vocab) – ฝึกจำคำศัพท์ 📚

เว็บแอปสำหรับท่องคำศัพท์ภาษาอังกฤษ **ชุด 3000 คำ** (2,981 คำ ระดับ A1–B2) และ **ชุด 5000 คำ** (คำเพิ่มอีก 1,976 คำ ระดับ B2–C1) ตามรายการ Oxford 3000™ / Oxford 5000™ รวม 4,957 คำ พร้อมคำแปลไทย ออกแบบมาให้ใช้บน iPhone เป็นหลัก
ติดตั้งเป็นแอปบนหน้าจอโฮม (PWA) ได้ และใช้งานออฟไลน์ได้

## ฟีเจอร์
- 🃏 **แฟลชการ์ด + ทบทวนเป็นระยะ (Spaced Repetition)** – แตะเพื่อพลิก ปัดขวา = จำได้, ปัดซ้าย = ลืม
  แล้วระบบจะนัดให้กลับมาทบทวนตามช่วงเวลาที่เหมาะสม (1, 3, 7, 16, 35 วัน …)
  - ด้านหลังการ์ดมี **ประโยคตัวอย่าง** พร้อมคำแปลไทย และกดฟังเสียงประโยคได้
  - ปุ่ม **"รู้คำนี้แล้ว ข้ามเลย"** สำหรับคำที่รู้อยู่แล้ว จะได้ไม่เสียเวลา
  - ปุ่ม **↩︎ ย้อนกลับ** เผื่อกดผิด
  - กด **"ยาก"** กับคำใหม่ การ์ดจะวนกลับมาอีกครั้งในรอบเดียวกัน
  - กด **☆** เพื่อติดดาวคำที่ชอบจำผิด แล้วเลือกเล่นเกมเฉพาะคำติดดาวได้
- 📱 **ไถศัพท์** – ปัดขึ้นทีละคำแบบฟีดไม่มีวันจบ มีคำใหม่ คำทบทวน คำถามหลายแบบ การ์ดพิเศษ (ครอบครัวคำ คำคู่กัน คำสับสน ประโยคจากเรื่องสั้น) บอสคำดื้อ การ์ดจับเวลา โหมดไฟลุก และการ์ดสรุป
- 📈 **สถิติและการคาดการณ์** – กราฟความถี่ที่เล่น แนวโน้มคำที่จำได้ และคาดว่าจะจำครบ 3000/5000 คำเมื่อไร
- ⚡ **เล่นด่วน** – แตะครั้งเดียว เกมสุ่ม 10 ข้อ
- ⭐ **XP และเลเวล** – ได้ XP จากทุกการ์ดและคำตอบ ตอบถูกติดกันได้โบนัสคอมโบ
- 🎯 **แบบทดสอบวัดระดับ** – ข้ามคำที่รู้อยู่แล้วทีละหลายร้อยคำ
- 🏆 **อันดับเพื่อน** และ 🔔 **แจ้งเตือนรายวัน** (เมื่อเปิดซิงก์ Supabase)
- 🐢 **คำดื้อ + วิธีจำของฉัน** – จับคำที่ลืมบ่อย ให้เขียนวิธีจำของตัวเองโชว์บนการ์ด
- 📖 **อ่านเรื่องสั้น** ห้องสมุด 105 เรื่อง (A1–C2) พร้อมคำแปล คำถาม เสียงอ่านที่ไฮไลต์ตามย่อหน้า และโหมดฟังอย่างเดียว แตะคำเพื่อดูความหมาย
- 🔗 **คำที่มักใช้คู่กัน** (collocations) ในหน้ารายละเอียดคำ + เกมคำคู่กัน
- 🤔 **คำที่คนไทยสับสนบ่อย** 44 คู่ พร้อมวิธีแยก + เกม · 👂 **ฝึกหูแยกเสียง** (ship/sheep, light/right) 93 คู่
- 🧬 **ครอบครัวคำ** 245 ครอบครัว (decide → decision → decisive → decisively) ในหน้ารายละเอียดคำ + หน้ารวม + เกมเปลี่ยนรูปคำ
- 📒 **สมุดสติกเกอร์** 16 หมวด อัปเกรด 🥉→🥈→🥇→💎 ตามคำที่จำได้
- 🔀 **เกมเรียงประโยค** และเกมจากเรื่องสั้นที่อ่านแล้ว (เติมคำ / เรียงประโยค)
- 🎨 เลือกเสียงอ่าน (รองรับเสียง Enhanced/Premium ของ iOS) และธีมสว่าง/มืด · 📅 สรุปรายเดือน
- 📂 **เรียนตามหมวด** 16 หมวด เช่น อาหาร การเดินทาง งาน
- ☁️ **ซิงก์ข้อมูล** ผ่าน Supabase (ไม่บังคับ) ดู [SYNC-SETUP.md](SYNC-SETUP.md)
- 🎮 **มินิเกม 10 แบบ** – ทายความหมาย, ทายคำศัพท์, ฟังแล้วตอบ, สะกดคำ, เติมคำในประโยค, จับคู่แข่งเวลา, 🎤 พูดตาม (ใช้ไมค์), ฝึกคำที่ผิดบ่อย, ✍️ ฟังประโยคแล้วเขียน, 🗣️ พูดทั้งประโยค
  (มีคอมโบ สถิติคะแนน เสียงเอฟเฟกต์ และพลุฉลองเมื่อทำได้ดี 🎉)
- 🔊 อ่านออกเสียงด้วยเสียงของ iOS (เลือกสำเนียงอเมริกัน/อังกฤษ และความเร็วได้)
- 📖 ค้นหาคำศัพท์ภาษาอังกฤษหรือไทย กรองตามระดับและสถานะ แตะคำเพื่อดูรายละเอียดและประโยคตัวอย่าง
- 🔥 นับวันที่เรียนต่อเนื่อง พร้อม 🧊 ตัวกันสตรีคขาด (ได้ 1 อันทุก 7 วันติด เก็บได้สูงสุด 2 อัน)
- 🎯 ภารกิจรายวันที่เปลี่ยนทุกวัน และ 🏅 เหรียญรางวัล 24 เหรียญ
- 📊 กราฟ 7 วันล่าสุด, 📅 พยากรณ์การ์ดที่ต้องทบทวน 7 วันข้างหน้า, ความคืบหน้าแยกตามระดับ
- ⏰ เพิ่มการเตือนรายวันลงปฏิทิน iPhone (ไฟล์ `.ics` ในโฟลเดอร์ `reminders/`)
- 🌙 รองรับโหมดมืด และ safe area ของ iPhone (Dynamic Island / แถบโฮม)
- 💾 สำรอง/นำเข้าความคืบหน้าเป็นไฟล์ JSON
- 📘 คู่มือการใช้งานและทริกการจำศัพท์ในแอป (ปุ่มในหน้าตั้งค่า)

## ระดับคำศัพท์
| ระดับในแอป | ลิสต์ | จำนวน |
|---|---|---|
| A1, A2, B1, B2 | Oxford 3000 | 2,981 คำ |
| B2+ | Oxford 5000 (เพิ่มเติม) ระดับ B2 | 698 คำ |
| C1 | Oxford 5000 (เพิ่มเติม) ระดับ C1 | 1,278 คำ |

เลือกระดับที่ต้องการได้ในหน้า **ตั้งค่า** (เลือกได้หลายระดับพร้อมกัน)
มี 19 คำที่อยู่ในทั้งสองลิสต์แต่มีความหมายใหม่ใน 5000 (เช่น *minute* = เล็กมาก) ซึ่งเพิ่มความหมายนั้นไว้ในการ์ดเดิมแล้ว

## เปิดใช้งานผ่าน GitHub Pages
1. ไปที่ **Settings → Pages** ของ repo นี้
2. ที่ **Build and deployment** เลือก Source = `Deploy from a branch`, Branch = `master` และโฟลเดอร์ `/ (root)` แล้วกด Save
3. รอประมาณ 1 นาที แล้วเปิด `https://<username>.github.io/essential-vocab/`

## ติดตั้งบน iPhone
เปิดลิงก์ด้วย **Safari** → กดปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม**
แอปจะเปิดแบบเต็มจอ ใช้ได้แม้ไม่มีเน็ต และข้อมูลการเรียนจะเก็บไว้ในเครื่อง

## แหล่งข้อมูล
รายการคำ ระดับ CEFR และคำอ่าน อ้างอิงจากรายการ Oxford 3000 และ Oxford 5000 (ฉบับปรับปรุงปี 2019) ของ Oxford University Press
คำแปลภาษาไทยและประโยคตัวอย่างเขียนขึ้นใหม่ทั้งหมด (ไม่ได้คัดลอกจาก Oxford) แบบสั้นเพื่อช่วยจำ (อาจไม่ครอบคลุมทุกความหมาย) – ดูความหมายเต็มได้จากลิงก์ Oxford Learner's Dictionaries บนการ์ด

> **ข้อจำกัดความรับผิดชอบ:** Oxford 3000™ และ Oxford 5000™ เป็นเครื่องหมายการค้าของ Oxford University Press
> แอปนี้เป็นโปรเจกต์ส่วนตัว ไม่มีส่วนเกี่ยวข้อง ไม่ได้รับการสนับสนุน และไม่ได้รับการรับรองจาก Oxford University Press
