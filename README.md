# Oxford 3000 – ฝึกจำคำศัพท์ 📚

เว็บแอปสำหรับท่องคำศัพท์ **Oxford 3000** (2,981 คำ ระดับ A1–B2) พร้อมคำแปลไทย ออกแบบมาให้ใช้บน iPhone เป็นหลัก
ติดตั้งเป็นแอปบนหน้าจอโฮม (PWA) ได้ และใช้งานออฟไลน์ได้

## ฟีเจอร์
- 🃏 **แฟลชการ์ด + ทบทวนเป็นระยะ (Spaced Repetition)** – แตะเพื่อพลิก ปัดขวา = จำได้, ปัดซ้าย = ลืม
  แล้วระบบจะนัดให้กลับมาทบทวนตามช่วงเวลาที่เหมาะสม (1, 3, 7, 16, 35 วัน …)
- 🎮 **มินิเกม 6 แบบ** – ทายความหมาย, ทายคำศัพท์, ฟังแล้วตอบ, สะกดคำ, จับคู่แข่งเวลา, ฝึกคำที่ผิดบ่อย
- 🔊 อ่านออกเสียงด้วยเสียงของ iOS (เลือกสำเนียงอเมริกัน/อังกฤษ และความเร็วได้)
- 📖 ค้นหาคำศัพท์ภาษาอังกฤษหรือไทย กรองตามระดับและสถานะการเรียนได้
- 🔥 นับวันที่เรียนต่อเนื่อง, เป้าคำใหม่ต่อวัน, ความคืบหน้าแยกตามระดับ
- 🌙 รองรับโหมดมืด และ safe area ของ iPhone (Dynamic Island / แถบโฮม)
- 💾 สำรอง/นำเข้าความคืบหน้าเป็นไฟล์ JSON

## เปิดใช้งานผ่าน GitHub Pages
1. ไปที่ **Settings → Pages** ของ repo นี้
2. ที่ **Build and deployment** เลือก Source = `Deploy from a branch`, Branch = `master` และโฟลเดอร์ `/ (root)` แล้วกด Save
3. รอประมาณ 1 นาที แล้วเปิด `https://<username>.github.io/language-3000-oxfords/`

## ติดตั้งบน iPhone
เปิดลิงก์ด้วย **Safari** → กดปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม**
แอปจะเปิดแบบเต็มจอ ใช้ได้แม้ไม่มีเน็ต และข้อมูลการเรียนจะเก็บไว้ในเครื่อง

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `style.css` | หน้าตา (mobile-first) |
| `app.js` | ตรรกะแฟลชการ์ด เกม และการเก็บความคืบหน้า |
| `words.js` | รายการคำ: `[คำ, ชนิดคำ, ระดับ CEFR, คำอ่าน IPA, คำแปลไทย]` |
| `sw.js` | Service worker สำหรับใช้งานออฟไลน์ (แก้ไฟล์แล้วให้เปลี่ยน `VERSION`) |

## แหล่งข้อมูล
รายการคำ ระดับ CEFR และคำอ่าน อ้างอิงจากรายการ Oxford 3000 ของ Oxford University Press
คำแปลภาษาไทยเขียนขึ้นใหม่แบบสั้นเพื่อช่วยจำ (อาจไม่ครอบคลุมทุกความหมาย) – ดูความหมายเต็มได้จากลิงก์ Oxford Learner's Dictionaries บนการ์ด
