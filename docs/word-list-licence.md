# รายการคำกับลิขสิทธิ์: ถ้าจะขายแอปต้องเปลี่ยนอะไร

> บันทึกสำหรับผู้พัฒนา (1.126) — สรุปจากข้อมูลที่หาได้ ณ พ.ย. 2569 **ไม่ใช่คำปรึกษาทางกฎหมาย** ถ้าจะขายจริงควรให้นักกฎหมายดูอีกครั้ง

## ตอนนี้อะไรมาจาก OUP บ้าง
| ส่วน | ที่มา | ความเสี่ยงถ้าขาย |
|---|---|---|
| **การเลือกคำ** 4,957 คำ (ชุด 3000/5000) | Oxford 3000™ / 5000™ ผ่านไฟล์ CSV บน GitHub | สูง: การคัดเลือกและจัดกลุ่มเป็นงานรวบรวมที่มีลิขสิทธิ์ และชื่อเป็นเครื่องหมายการค้า |
| **ระดับ CEFR** ของแต่ละคำ | Oxford | สูง: เป็นการตัดสินของ OUP |
| **คำอ่าน IPA** | Oxford | ปานกลาง: ถอดเสียงแบบเดียวกับพจนานุกรม |
| ชนิดคำ (POS) | Oxford | ต่ำ: เป็นข้อเท็จจริงทางภาษา |
| คำแปลไทย ประโยคตัวอย่าง เรื่องสั้น เกม ข้อมูลอื่นทั้งหมด | เขียนขึ้นเอง | ไม่มี |

แอปไม่ได้ใช้ชื่อ Oxford เป็นชื่อแบรนด์แล้ว (ตั้งแต่ 1.8.1) แต่รายการคำกับระดับยังมาจาก OUP

## ทางเลือกที่ใช้สัญญาอนุญาตแบบเปิด
### 1. NGSL 1.2 (New General Service List) — แนะนำเป็นแกนหลัก
- 2,809 คำที่ใช้บ่อยที่สุดในภาษาอังกฤษทั่วไป โดย Browne, Culligan และ Phillips (2013)
- สัญญาอนุญาต **Creative Commons BY-SA 4.0**: เว็บของโครงการระบุว่าใช้ในงานเชิงพาณิชย์ได้
- เงื่อนไข: ต้อง **ให้เครดิต** และ **ShareAlike** หมายความว่ารายการคำที่ดัดแปลงต้องเผยแพร่ด้วยสัญญาอนุญาตเดียวกัน (ไฟล์ `data/words/*.js` ต้องเปิดตาม แต่โค้ดแอปไม่จำเป็น)
- มีรายการเสริมจากโครงการเดียวกัน: NGSL-Spoken, NAWL (ศัพท์วิชาการ), TSL (TOEIC), BSL (ธุรกิจ) ใช้แทนชุด 5000 บางส่วนได้
- **ข้อเสีย:** ไม่มีระดับ CEFR ต้องแบ่งระดับเองตามความถี่ (เช่น 500 คำแรก = A1)
- ระวังสับสนกับ “new-GSL” ของ Brezina & Gablasova (2,494 คำ) ซึ่งเป็นคนละรายการ

### 2. CEFR-J Wordlist — ถ้าอยากได้ระดับ A1–B2 สำเร็จรูป
- ราว 7,800 คำ แบ่งระดับ A1–B2 โดย Tono Laboratory มหาวิทยาลัย TUFS
- ที่เก็บข้อมูลบน GitHub (olp-en-cefrj) บอกว่าใช้เชิงพาณิชย์ได้ฟรีถ้าอ้างอิงถูกต้อง **แต่ยังไม่ได้ยืนยันจากเว็บทางการ**: ต้องตรวจที่ cefr-j.org หรือถาม Tono Lab ก่อน
- ไม่มีระดับ C1 ต้องเสริมคำ C1 จากที่อื่น (เช่น NAWL)

### 3. คำอ่าน IPA
- **CMUdict** (สัญญาอนุญาตแบบ BSD ใช้เชิงพาณิชย์ได้) เป็นเสียงอเมริกันแบบ ARPAbet แปลงเป็น IPA ด้วยสคริปต์ได้
- **Wiktionary** (CC BY-SA) มี IPA ทั้ง UK/US แต่ต้องให้เครดิตและ ShareAlike เหมือน NGSL

## ผลเทียบล่าสุด (1.235.0)
ขั้นที่ 1 ด้านล่างทำแล้วด้วย `tools/licence-audit.js` ผลเต็มอยู่ใน [word-list-audit.md](word-list-audit.md) (รันใหม่ได้ทุกเมื่อ วิธีดาวน์โหลดไฟล์อยู่หัวสคริปต์) สรุป ณ พ.ย. 2569:
- คำชุดหลัก 4,957 คำ **อยู่ใน NGSL หรือ NAWL แล้ว 3,565 คำ (ราว 72 %)** เก็บคำแปลและตัวอย่างเดิมได้เลย ระดับ A1–B2 ตรงกันราว 85–87 % ส่วนที่หลุดส่วนใหญ่อยู่ใน B2+ และ C1 (C1 อยู่ในรายการแบบเปิดแค่ราว 39 %)
- ต้องเขียนคำใหม่เพิ่มแค่ราว 30 คำจาก NGSL (เช่น percent, voter, supplier, grammar, verb) และราว 20 คำจาก NAWL (ส่วนใหญ่เป็นอุปสรรคอย่าง anti, micro, semi ที่อาจไม่ต้องใส่)
- คำอ่าน: CMUdict มีครบเกือบ 100 % (ต้องแปลง ARPAbet เป็น IPA และเป็นสำเนียงอเมริกันอย่างเดียว)
- ระดับ: ถ้าแบ่งตามอันดับความถี่ของ NGSL จะตรงกับระดับเดิมราว 44 % ต่างกัน 1 ระดับราว 40 % จึงต้องตั้งเส้นแบ่งเองแล้วตรวจด้วยมือ
- **ทางที่น่าจะคุ้มที่สุด:** ใช้ NGSL + NAWL เป็นแกน A1–B2 แทนชุด 3000 แทบไม่เสียอะไร ส่วน C1 / B2+ ที่หลุดราว 1,050 คำ ต้องเลือกว่าจะตัด หรือหารายการแบบเปิดอื่นมาแทน (เช่น CEFR-J ถ้ายืนยันสัญญาอนุญาตได้)

## ถ้าตัดสินใจเปลี่ยน: ขั้นตอนที่เสนอ
1. ทำตารางเทียบคำปัจจุบันกับ NGSL + NAWL (+ CEFR-J ถ้ายืนยันสัญญาอนุญาตได้) ว่าคำไหนมีอยู่แล้ว คำไหนต้องตัด คำไหนต้องเพิ่ม
2. คำที่อยู่ในทั้งสองรายการ: **เก็บคำแปลไทยและประโยคตัวอย่างเดิมไว้ได้** (เขียนเองทั้งหมด) เปลี่ยนแค่ระดับกับ IPA
3. คำใหม่: เขียนคำแปลไทยและตัวอย่างใหม่ตามแนวเดิม
4. ตั้งระดับเอง (จากความถี่ใน NGSL หรือ CEFR-J) และสร้าง IPA จาก CMUdict
5. **ความคืบหน้าผู้ใช้ไม่หาย:** `prog` เก็บตามตัวสะกดของคำ คำที่ยังอยู่จะเก็บความคืบหน้าเดิม คำที่ถูกตัดก็แค่ไม่แสดง
6. เปลี่ยนข้อความในแอป: ชื่อชุด “3000/5000 คำ” ข้อความปฏิเสธความรับผิดชอบท้ายหน้าตั้งค่า README หัวข้อ “แหล่งข้อมูล” และเพิ่มเครดิต CC BY-SA
7. ไฟล์รายการคำที่ดัดแปลงจาก NGSL ต้องประกาศสัญญาอนุญาต CC BY-SA 4.0 ในไฟล์ด้วย
